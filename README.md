# PA2 - Programación Orientada a Objetos

## Descripción
Este proyecto consiste en una aplicación web llamada Cotizador, desarrollada con JSP y Apache Tomcat. Permite ingresar los datos de un cliente y un producto, validar la información, calcular descuentos e IGV y mostrar el total a pagar.

## Tecnologías utilizadas
- Java
- JSP
- Apache Tomcat
- HTML
- CSS
- GitHub

## Archivos del proyecto
- `index.jsp`: contiene el formulario para ingresar los datos.
- `resultado.jsp`: valida los datos, realiza los cálculos y muestra el resultado de la cotización.

## Funcionalidades
- Validación del nombre y correo electrónico.
- Validación del precio, cantidad y descuento.
- Cálculo del subtotal.
- Aplicación del descuento.
- Cálculo del IGV.
- Presentación del total a pagar.
- Mensajes de error cuando los datos son incorrectos.
